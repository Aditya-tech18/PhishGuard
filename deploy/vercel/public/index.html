How this check works & privacy

The bundled classifier evaluates lexical features of the URL origin. The selected model ignores the path and query, so it cannot classify individual pages. It does not contact the submitted website, follow redirects, inspect its certificate or see its page content. Domain-group separation was used for this dataset evaluation; source and time bias may remain.

The application does not retain submitted URLs or results. Your URL is transmitted to this deployment after consent. Hosting providers may maintain request metadata; application-level minimization is not a promise about provider logging. Keep the server key private. This cloud profile has no screenshot, Spark or Kafka runtime; those are available in the local project.
